# 新增科別說明

新增一個科別**不需要改程式**：準備單張、寫一份設定檔、重新部署即可。

## 1. 架構

```
knowledge/
  hemato-oncology/manifest.json   ← 血液腫瘤科（單張在 Obsidian_Vault/衛教知識庫/）
  cardiology/manifest.json        ← 新科別
衛教單張可以放在任何資料夾，由 manifest 的 source_dir 指定
```

每位病患屬於一個科別（管理者建立病患時選擇；未選則為預設科別）。科別決定：

| 項目 | 說明 |
|---|---|
| 知識庫範圍 | 只檢索該科別的單張 |
| 紅旗 | **通用核心**（胸痛、呼吸困難、意識改變、出血、脫水、過敏、外傷、自傷）所有科別都適用；**發燒等級、體溫門檻與額外規則**由科別設定 |
| 症狀評估 | 每個科別自己的症狀清單、追問與升級門檻 |
| 緊急電話 | 每個科別可以不同 |
| 急症回覆的第一句 | 可依紅旗類別覆寫，例如引用本科的單張 |

## 2. 準備單張

每份單張是一個 Markdown 檔，開頭要有 frontmatter：

```markdown
---
title: 心衰竭居家照護
code: CV-01                # 單張代碼，同科別內不可重複；回答會標註這個代碼
topic: 心衰竭
category: 心臟             # 必填
doc_version: 2025.01 一版  # 改版時一定要更新，系統才會換掉舊版內容
rag_index: true            # false = 停用（會從知識庫移除）
---

# 心衰竭居家照護

## 居家照護
……

## 何時通知醫護人員
……
```

- 章節用 `## 標題` 分段；`## 參考資料`、`## 護理指導評值` 不會進入知識庫。
- 科別設定好之後，單張也可以由管理者在網頁「單張管理」上傳 Word／PDF（見 [單張管理後台.md](單張管理後台.md)），不必手寫 frontmatter。
- **單張內容照院內核可版本放，不要改寫。**

## 3. 寫設定檔 `knowledge/<科別代號>/manifest.json`

資料夾名稱就是科別代號，必須與 `id` 相同。以 `_` 開頭的欄位是註解，系統會忽略。

```json
{
  "id": "cardiology",
  "name": "心臟內科",
  "source_dir": "knowledge/cardiology/leaflets",
  "emergency_contact": "請立即撥打 119，或聯絡心臟內科 (02) xxxx-xxxx",

  "redflag": {
    "_說明": "心衰竭病人：體重快速增加、無法平躺為急症；發燒不是本科主要急症，維持 MEDIUM",
    "fever_level": "medium",
    "temp_high": null,
    "temp_medium": 38.0,
    "extra_high": [
      ["cardiorespiratory", "無法平躺"],
      ["cardiorespiratory", "re:體重.{0,6}(增加|多了).{0,4}(2|兩|二)公斤"]
    ],
    "extra_medium": [["symptom", "腳腫"]]
  },

  "safety_text": {
    "cardiorespiratory": "喘到無法平躺或胸痛，可能是心衰竭惡化，需要立即處理（衛教單張 CV-01）。"
  },

  "assessment": [
    {
      "key": "edema", "name": "下肢水腫", "keywords": ["腳腫", "水腫"],
      "doc_code": "CV-02",
      "field": "days", "question": "腫了幾天呢？（請給個數字）",
      "escalate_count": 3
    }
  ]
}
```

| 欄位 | 說明 |
|---|---|
| `emergency_contact` | 空字串 = 沿用 `.env` 的 `EMERGENCY_CONTACT` |
| `redflag.fever_level` | 發燒詞的等級：`high`（例如化療科別）或 `medium` |
| `redflag.temp_high`／`temp_medium` | 體溫達到這個值判 HIGH／MEDIUM；`null` = 不判 |
| `redflag.extra_high`／`extra_medium` | 本科額外規則：`[類別, 關鍵字]`，或 `[類別, "re:正規表示式"]` |
| `safety_text` | 依類別覆寫急症回覆第一句；類別有 fever、bleeding、cardiorespiratory、neuro、dehydration、allergy、injury。**自傷回覆不可覆寫** |
| `assessment[].field` | `count`（次數）、`days`（天數）或省略 |
| `assessment[].escalate_count`／`high_count` | 次數或天數達到此值 → 升級為 MEDIUM／HIGH；ESAS 分數 ≥7 一律升級 |
| `assessment[].escalates` | `false` = 永不升級（例如落髮） |

設定檔有錯（缺欄位、`source_dir` 不存在、`id` 與資料夾不符）時，系統**啟動即失敗**，不會帶著錯誤設定上線。

## 4. 套用

```bash
# 本機
python -X utf8 scripts/index_vault.py      # 同步向量索引（只處理有變動的單張）

# Docker：若單張不在 Obsidian_Vault/衛教知識庫/，先在 Dockerfile 加一行 COPY 該資料夾
docker compose --profile https up -d --build   # 啟動時自動同步
```

之後在管理者畫面建立病患時選擇新科別即可。
